# The code route, as it last stood

The three files beside this one are the last builds of the write phase's
code route, from prompt set 1.13.0: the prompt a developer would hand to a
code assistant with a terminal, which reads the shop from its homepage
through the platform's API with a read-only key, runs the linter and writes
the sheets as files. They are kept here as the starting point of the
developer version, which has its own instructions to come.

They are a snapshot. Nothing builds them, the site does not serve them, and
the prompt set's version moves without them. The chat set, which the site
serves, is the folder above; its sources carry no code route since prompt
set 1.14.0.

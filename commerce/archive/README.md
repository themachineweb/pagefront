# Commerce archive

The frozen record of drafts before commerce release 0.3.0: superseded spec drafts, sketches, schemas and case-study artifacts, kept verbatim.

Nothing is added here. From release 0.3.0 the history of the commerce vertical is in git tags (`commerce-v<release>`), in each spec document's changelog, and in the frozen schema store ([`../schemas/`](../schemas/)), which holds every published JSON Schema. See [`../spec/releases.md`](../spec/releases.md).

The files keep the names they were archived under. The versions in those names are legacy format versions.

- [`organization-v0_1.md`](organization-v0_1.md) — the Commerce Organization Sheet spec as first ratified (2026-08-14), superseded by later revisions of [`../spec/organization.md`](../spec/organization.md) starting with authorized resellers (2026-08-31).
